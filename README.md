# Omnevum

Pronounced om-nee-VEE-um, like continuum.

[![deploy](https://github.com/shfqrkhn/shfqrkhn.github.io/actions/workflows/deploy.yml/badge.svg)](https://github.com/shfqrkhn/shfqrkhn.github.io/actions/workflows/deploy.yml) [![health](https://github.com/shfqrkhn/shfqrkhn.github.io/actions/workflows/health.yml/badge.svg)](https://github.com/shfqrkhn/shfqrkhn.github.io/actions/workflows/health.yml) [![licence: MIT](https://img.shields.io/badge/licence-MIT-blue.svg)](LICENSE)

Small local-first apps, tools, games, guides, recipes and courses, published at https://shfqrkhn.github.io.
Everything works offline and installs as an app. Data stays on your device. No account, no tracking.

This repository is the whole project: the apps, the builder that turns them into the site, the framework documents, and the checks that keep it trustworthy. Nothing is generated by hand and nothing generated is committed: GitHub builds and deploys the site on every push.

## How it fits together

```text
sources/apps/*.html   one self-contained HTML file per app (authored)
builder/registry.json  every page: name, address, colour, archive state (the one source of truth)
        |
        v   python builder/build.py        validate, build, run every gate
site/                  the published site (generated pages, worker, manifest) plus authored scripts/ and content/
        |
        v   .github/workflows/deploy.yml   build, test, deploy to GitHub Pages
https://shfqrkhn.github.io
```

## Repository map

| Path | What it holds |
|---|---|
| `sources/apps/` | The apps, one file each, versioned in the file name |
| `sources/method/` | The AI method documents: Omni, the Prompt Clipboard, the Knowledge Distiller, the Resource Catalogue |
| `builder/` | The builder and every tool: build, rename, archive, new app, publish, backup, self-test, icon restore; the registry, icon list, install icons |
| `site/` | The published site. Authored: `scripts/` (design system, page generator, checks, tests; `ui-icons.json` there is generated), `content/` (generated pages' data), `robots.txt`. Generated and git-ignored: everything else |
| `docs/` | `FRAMEWORK.md` (how everything works: start here) and `PRIVACY.md` |
| `converge/` | Scripts for reviewing the documents with AI cheaply (`scan.py`, `omni_check.py`, `apply_edits.py`) and their receipts |
| `.github/workflows/` | `deploy.yml` (build, test, deploy) and `health.yml` (weekly check that the live site still matches) |
| `AGENTS.md` | Instructions for AI coding agents working on this repository |
| `CONTRIBUTING.md` | How to propose a change: edit sources, run the build and self-test, no personal data |
| `SECURITY.md` | How to report a vulnerability or a privacy leak, and how the repository is kept safe |

## Work on it

Python 3.12 or newer, on Windows, macOS or Linux (CI builds on Windows). The browser tests need Playwright: `python -m pip install -r requirements.txt` then `python -m playwright install chromium`.

```bash
python builder/build.py                              # build site/ and run every gate
python builder/selftest.py                           # prove the framework works and its guards bite
python builder/new_app.py <kind> <slug> "<Title>" --topic <topic> --blurb "<up to 20 words>"
python builder/rename.py "<page>" "<New Name>"       # rename or recolour a page, old links keep working
python builder/archive.py list                       # move pages in or out of the hub Archive
python builder/publish.py "message" --yes            # commit, push, wait until the live site matches
python builder/fetch_icons.py                        # restore the full icon pack (only icons in use are stored)
python builder/backup.py                             # zip the repository plus local-only files
```

Everything about how pages are made, added, moved and published is in [docs/FRAMEWORK.md](docs/FRAMEWORK.md). No personal information, ever: [docs/PRIVACY.md](docs/PRIVACY.md).

## What is not in this repository, on purpose

- Generated pages, the offline worker and the manifest: `python builder/build.py` rebuilds them, and the deploy workflow does it on every push.
- The full Phosphor icon pack: `python builder/fetch_icons.py` downloads the pinned version.
- `builder/privacy_names.txt`, the private list of names that must never appear. It is kept off GitHub by design. CI reads it from the repository secret PRIVACY_NAMES (one name per line) and hides any match in its logs; without the secret the pattern checks run alone.
