    Help

    Add

    Type a line, press Enter.

    • #tag tag. !high or !low priority.
    • @Home drawer (group). @My_Group for spaces.
    • today tomorrow friday +3d +2w 2026-11-02 due date.
    • every day every week every month repeat.

    Save

    Saved in this browser as you go. Export JSON is your backup; Import JSON restores it. Clearing site data erases the list.

    Undo

    Most changes can be undone for 10 s (Ctrl+Z).

    Keys

    • Ctrl+/ search. Alt+N add with details.
    • Up and Down arrows move between tasks. Enter edits. Delete removes.
    • My order sort: Drag button, Space grabs, arrows move, Space drops, Esc cancels.

    Focus

    Tap Focus on a task. The timer survives a reload.

    Offline

    TickleTodo Tasks makes no network requests. Templates are built in.
