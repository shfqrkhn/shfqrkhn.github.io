      Help

      Everything stays on this device. Nothing is sent anywhere. Values you type in a fill-in form are not saved.

      Mark a blank in a prompt with {{name}}. Names start with a letter and use letters, digits and underscores, and capitals matter. Every use of a name is filled. To show the characters literally, write \{{. A filled value is never scanned again.

      Copy is blocked while a required blank is empty. If the browser refuses the clipboard, the preview is selected so you can copy it yourself.

      A kind only supplies section labels. Fragments are reusable blocks you insert as a copy. Prompts of 50,000 characters or more are refused, never cut.

      Text written as [LABEL: hint] can be converted to a blank. You choose; nothing is converted on its own.

      Save a copy writes all prompts to a file. Restore shows what the file holds, then replaces the whole library or nothing.

      Images are not stored. If a prompt expects a picture, attach it in the tool you paste into.
