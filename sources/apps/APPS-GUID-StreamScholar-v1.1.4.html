Edit channels

  1. Copy this file first.
  2. Open it in a plain text editor. Find dataVersion. The list follows.
  3. Edit text between the quote marks. To add, copy one whole entry and paste it in a group:
{ "name": "Channel Name", "url": "https://www.google.com/search?q=Channel%20Name", "subscribers": "1.2M", "description": "One sentence." },
  1. Update dataVersion and date. Save. Reload.

Keep every quote, comma and bracket. If the list breaks, undo or use your copy. Accent colour: edit --accent-light and --accent-dark (six-digit codes).
