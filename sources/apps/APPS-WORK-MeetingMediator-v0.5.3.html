MeetingMediator Sessions

Help

Start. Create a workspace, then a matter. Follow the steps in order.

Your data stays in this browser (database name: commonground-suite). Clearing site data erases it. Nothing leaves the device unless you use the optional AI facilitator.

Backup. Settings, then Export. The file is not encrypted and holds names and notes: keep it private.

Restore. Settings, then Import. The file is checked first. An import adds a copy (Imported) and never overwrites. After a Factory Reset, use Import backup on the setup screen.

Delete. One matter: open it, All sections, Delete Matter. Everything: Settings, Factory Reset.

Facilitation. Open a matter, then Open facilitation. One device, one prompt per screen. Cards are anonymous and hidden until everyone finishes. The timer survives a reload. Anyone may pass. Agreements have an owner and a date, with a reminder. None of it goes to the AI facilitator.

AI facilitator (optional). Sends the matter text, which may include names, to Google Gemini or OpenAI, using your own key. Your key lives in this tab only.

Edit methods and colours

Open this file in a plain text editor (not Word). Keep a copy. Search cg-templates: it holds every method and prompt. Change only the words inside quotes, and update dataVersion and date. For colour, change the number after --hue in the html tag (0 to 359).

Do not edit the script parts: they are locked to a checksum and the app will not start. To update the app, replace the file. Saved data stays.

Method descriptions

The method templates are written in this app's own words from these public pages, read on 2026-10-30. Each page is licensed CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/); the template wording is shared on the same terms.

1-2-4-All: Liberating Structures, http://www.liberatingstructures.com/1-2-4-all/. The final Record step is added by this app.

Check-in and check-out rounds, and circle rounds: Sociocracy 3.0 patterns Check In and Rounds, https://patterns.sociocracy30.org/check-in.html and https://patterns.sociocracy30.org/rounds.html. The one-tap Pass and the Record step are added by this app.

Dot voting: Wikipedia, Dotmocracy, https://en.wikipedia.org/wiki/Dotmocracy. The number of dots per person is a setting, not a rule from the source.

Neutral wording: the template text avoids the words listed in the test file test_fz.py, which cites the Retrospective Prime Directive (retrospectivewiki.org, CC BY) and the Google SRE book chapter on blameless postmortems.
