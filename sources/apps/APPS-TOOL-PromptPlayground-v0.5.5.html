        Data
        
        
        Chats and settings stay in this browser. Keys stay in memory unless saved to the encrypted vault.
        
        
        Messages go only to the address shown under the message box.
        
        
        Words
        
        
        Provider: the service that writes answers. API key: your secret code for it. URL: its web address. Vault: locked storage for keys. CORS: a local server must allow web pages.
        
        
        
          More
        
        Export: JSON without keys, every branch. Chat as Markdown: the open branch. Full backup: includes keys, encrypted. Import asks before replacing.
        
        
        Markdown import: first line # title, then ## You and ## messages. Max 5 MB, 1000 messages. Added as a new chat.
        
        
        Branches: Regenerate and Edit keep old versions. Switch with Prev and Next.
        
        
        Cost shows only for models you price in Settings.
        
        
        Delete chat removes one chat. Wipe all removes everything here, including the vault.
        
        
        Keys: Enter sends. Shift+Enter adds a line. / opens prompts. Escape closes.
